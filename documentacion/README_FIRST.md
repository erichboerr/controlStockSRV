# 📘 Documentación del Proyecto ControlStock

Este directorio contiene guías y comandos útiles para instalar, configurar y mantener el sistema.

## Índice
- [🧪 Comandos de Migración](comandos_migracion.md)
- [📑 Instalación y configuración de Ubuntu Server](instalar_ubuntu_server.md)
- [🗄️ Instalación de PostgreSQL](instalar_base_de_datos.md)
- [🔒 Configuración HTTPS en Nginx](https.md)

## Uso recomendado
1. **Instalar Ubuntu Server** siguiendo la guía → preparar entorno con Node.js, PM2 y Nginx.  
2. **Instalar PostgreSQL** → crear usuario y base de datos para el backend.  
3. **Configurar HTTPS** → asegurar acceso a intranet.local desde clientes Windows.  
4. **Migraciones** → aplicar o revertir cambios en la base de datos con Sequelize.  

## 🚀 Resultado
Con estas guías, cualquier persona puede reproducir el entorno completo:  
- Servidor Ubuntu configurado.  
- Base de datos PostgreSQL lista.  
- Frontend y backend desplegados con Nginx + PM2.  
- Acceso seguro por HTTPS desde clientes Windows.
